
## About Dataset
This dataset contains loan application records, including applicant demographics, financial details, credit scores, and final loan approval outcomes.

It is specifically curated for data visualization, predictive modeling, and machine learning projects focused on credit risk analysis, loan approval prediction, and financial decision-making.

With attributes covering applicant age, gender, income, loan amount, credit score, and loan status, this dataset provides a strong foundation for analyzing loan approval trends, applicant profiles, and creditworthiness patterns.

Dataset Structure
File format: CSV
Rows: 1000
Columns: 7

Columns (features):
Applicant_ID → Unique identifier for each applicant
Age → Applicant’s age (in years)
Gender → Applicant’s gender (Male/Female)
Income → Applicant’s annual income (in local currency)
LoanAmount → Requested loan amount
CreditScore → Applicant’s credit score (numeric rating of creditworthiness)
Loan_Status → Loan decision outcome (Approved/Rejected)
